MINI SEARCH ENGINE: COMPLETE ACTIVITY (teacher copy, contains the solution)

What is in this folder
- search_engine.py      : the full working solution.
- articles.py           : the 12 articles the engine searches.
- search_engine_app.py  : the Gradio web page (step 9). It uses search_engine.py.
- requirements.txt      : gradio and a recent jinja2 (needed only for the web page).

Setup
1. Python 3.10 or newer.
2. For the web page:  pip install -r requirements.txt

Run
- The program:   python search_engine.py        (Windows: py search_engine.py)
- The web page:  python search_engine_app.py    then open http://127.0.0.1:7860

Expected results (teacher): WINS line is 6/10 for COUNT, 8/10 for TF and 10/10 for TF-IDF.
Do not share this folder with students: the boilerplate zip is the student copy.
